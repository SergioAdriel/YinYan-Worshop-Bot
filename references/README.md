# Captura de referencia

[captura/](captura/) contiene el último respaldo histórico que conserva esta carpeta. [BACKUP.json](captura/BACKUP.json) registra la fecha original y los hashes SHA-256 de los 152 archivos.

La implementación que se ejecuta está en la raíz del repositorio. Para recuperar un archivo de la captura, cópialo a una carpeta aparte y revisa las dependencias de esa versión.
